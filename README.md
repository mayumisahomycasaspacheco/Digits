# Digits
Digits is a console game collection made in Python. It started as a simple "guess the number" game. Now it's a small arcade where everything is about numbers.

![Digits](https://cdn.hackclub.com/01a12bae-6eb3-78ff-8913-d01ff61c3f93/image.png)

## What does it do?
When you run the program, a menu lets you choose between 4 mini-games:

1. **Guess the Number:** find the secret number with "higher" or "lower" hints. It has 3 difficulty levels and limited attempts.
2. **Lucky Dice:** bet coins on the sum of two dice (low, seven or high) and try not to go broke.
3. **Lightning Calculator:** solve 5 math problems as fast as you can. Your total time is measured.
4. **Digit Memory:** memorize a sequence of digits before it disappears. Every round gets one digit longer.
